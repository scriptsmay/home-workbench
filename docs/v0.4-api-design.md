# v0.4 Web 同步通道：云函数 HTTP API 契约与安全设计

> 实现基线：Web 端弃用 CloudBase jssdk，登录与同步改走单个云函数 `hwSyncApi` 的 HTTP 网关 API。
> 小程序端零改动，两端共用 `home_items` 集合。

## 1. 函数拓扑

单函数挂载，减少冷启动面与额度消耗：

| 项 | 值 |
|---|---|
| 函数名 | `hwSyncApi` |
| 运行时 | Nodejs18.15 |
| 类型 | Event（HTTP 网关触发） |
| 网关路由 | `POST/GET/OPTIONS` 于默认域名，路径前缀 `/api`，`EnablePathTransmission: true` |
| 子路由 | 函数内按 `httpMethod` + `path` 自管：`/api/auth/login`、`/api/sync/pull`、`/api/sync/push` |
| 默认访问域 | `https://trial-sh-d1gqznm4577d6a062-1251520283.ap-shanghai.app.tcloudbase.com` |

> 实测（2026-09-20）：SCF 路由 `EnableSafeDomain` 默认 true 但**不拦截自定义 Origin**，函数返回的 CORS 头原样透传。故 CORS 由函数自控（见 §5）。

## 2. 认证方案

**口令存储**（`home_users` 集合，见 §4）：

- 算法：Node 内置 `crypto.scrypt`，参数 `N=16384, r=8, p=1, keylen=64`；随机 16 字节 salt。
- 存储格式：`pwdHash = "<saltHex>:<hashHex>"`。校验用 `crypto.timingSafeEqual`。

**会话 Token**（无状态 HMAC 签名，密钥不下发浏览器）：

```
token = base64url(payloadJSON) + "." + base64url(HMAC_SHA256(secret, payloadB64))
payload = { uid, tv: <tokenVersion>, exp: <epochSeconds> }
```

- 密钥：函数环境变量 `HW_TOKEN_SECRET`（32+ 字节随机）。
- 有效期 `exp`：签发后 30 天。
- 全局吊销：把某用户的 `tokenVersion` +1，旧 token 立即失效（验签后比对 `tv`）。
- 校验失败（缺头 / 验签失败 / 过期 / tv 不符）一律 `401`。

**登录限速**（计数器字段在 `home_users`）：

- 每次口令错误 `failedCount++`；`failedCount >= 5` 时置 `lockedUntil = now + 15min`。
- 锁定期内即使口令正确也回 `429`。
- 登录成功：`failedCount=0`、`lockedUntil=null`。

## 3. 端点契约

所有响应 `Content-Type: application/json`；失败形如 `{ "error": { "code": "<machine>", "message": "<human>" } }`。

### 3.1 `POST /api/auth/login`

请求：
```json
{ "username": "string", "password": "string" }
```
响应 `200`：
```json
{
  "ok": true,
  "token": "<jwt-like>",
  "uid": "string",
  "username": "string",
  "nickname": "string|null",
  "expiresAt": "<ISO8601>"
}
```
错误：`401 invalid_credentials`（口令错，泛化文案）、`429 too_many_requests`（锁定）、`500`。

### 3.2 `POST /api/sync/pull`（需 `Authorization: Bearer <token>`）

请求体：`{}`（或空）。
响应 `200`：
```json
{ "ok": true, "data": { /* 全量 state，或 null（云端无数据=首次） */ }, "updatedAt": "<ISO8601|null>" }
```
> 首次无数据返回 `data:null` + `200`，与 v0.3 前端「静默处理 404」语义对齐。

### 3.3 `POST /api/sync/push`（需 `Authorization: Bearer <token>`）

请求：
```json
{ "data": { /* 全量 state */ }, "updatedAt": "<ISO8601>" }
```
行为：服务端读取 `home_items` 现存文档（`_id == uid`），执行与前端 v0.3 `mergeData` 等价的**字段级合并**（非空优先 + `updatedAt` 新者覆盖），写回。
响应 `200`：
```json
{ "ok": true, "data": { /* 合并后的权威 state */ }, "updatedAt": "<ISO8601>" }
```
> 回传合并结果，供客户端以服务端为准对齐本地。

### 3.4 `OPTIONS /api/*`（预检）

响应 `204` + CORS 头（见 §5）。不带响应体。

## 4. `home_users` 集合结构

```json
{
  "_id": "<uid>",
  "uid": "<uid>",
  "username": "<unique login name>",
  "pwdHash": "<saltHex>:<hashHex>",
  "nickname": "string|null",
  "tokenVersion": 0,
  "failedCount": 0,
  "lockedUntil": null,
  "createdAt": "<ISO8601>",
  "updatedAt": "<ISO8601>",
  "lastLoginAt": "<ISO8601|null>"
}
```

索引：`username` 唯一升序；`uid` 唯一（与 `_id` 冗余，保查询）。
`home_items` 保持不动（`_id == uid`，文档形如 `{ uid, data, updatedAt }`）。

**uid 连续性与账号发号**：

- CloudBase 内置认证用户体系弃用后，`home_users` 由管理端脚本直插发号，无自助注册。
- 为延续既有 Web 已同步数据，`home_users._id/uid` 复用旧 CloudBase-auth uid（首个已同步账号 uid = `2078905334118498305`），使其无需迁移即命中现有 `home_items` 文档。
- 新成员分配新稳定 uid；与小程序 `wx_<openid>` 文档的按人合并走后续绑定功能（本期不做，维持现状）。

## 5. CORS 策略（函数内 Origin 白名单）

允许列表（精确匹配 host，scheme 归一）：

- `https://home.virola-eko.com`
- `https://home.matishare.com`
- `https://home-workbench.pages.dev`
- `http://localhost:*`、`http://127.0.0.1:*`（本地调试）

命中白名单：回 `Access-Control-Allow-Origin: <echo Origin>`、`Vary: Origin`。
未命中：**不回任何 CORS 头**（浏览器侧拦截；curl 不受影响，便于负例验证）。
预检额外回：`Access-Control-Allow-Methods: POST, OPTIONS`、`Access-Control-Allow-Headers: Content-Type, Authorization`、`Access-Control-Max-Age: 86400`。
不使用 `Access-Control-Allow-Credentials`（用 Bearer token，非 Cookie）。

## 6. 错误码表

| HTTP | code | 语义 |
|---|---|---|
| 200 | — | 成功 |
| 400 | `bad_request` | 请求体缺字段 / JSON 解析失败 |
| 401 | `invalid_credentials` | 用户名或密码不正确（泛化） |
| 401 | `unauthorized` | 缺 token / 验签失败 / 过期 / 已吊销 |
| 404 | `not_found` | 未知子路由 |
| 429 | `too_many_requests` | 登录失败次数超限，锁定中 |
| 500 | `internal` | 未预期错误（不回堆栈） |

## 7. 环境变量（函数侧注入，不下发浏览器）

| 变量 | 用途 |
|---|---|
| `HW_TOKEN_SECRET` | HMAC token 签名密钥 |
| `TCB_ENV` | CloudBase envId（node-sdk 初始化，默认取运行时上下文） |
| `HW_ALLOWED_ORIGINS` | 逗号分隔 CORS 白名单（可选覆盖内置列表） |

## 8. 体验版额度口径

估算：家庭数个成员 × 每日若干次操作。按 `<1000 次/天 × 30 天` 比对体验版云函数调用次数与 Gb-s 配额；单函数聚合已省额度。上线后观察 Console 计量，触顶前告警。冷启动尖峰由前端「本地优先写入」兜住体感。
